# Achu Asokan — Portfolio

![Achu Asokan Portfolio Preview](./public/achuasokan-opengraph.webp)

A full-stack software engineer portfolio blending modern web architecture with a tactile **Paper & Ink / Artist Sketchbook** aesthetic. Built with **Next.js 16 (App Router)**, **React 19**, and **TypeScript**.

---

## ✨ Standout Features

- **Artisanal Signature Entrance**: A hand-drawn watercolor ink line with organic SVG turbulence filters, dual-tone metallic typography (*white-to-gold flow* + *brushed metallic gold*), and a soft watercolor wash exit.
- **Physical 3D Page Turn Engine**: An 18-strip nested CSS 3D transform chain that curls and flexes like real sketchbook paper.
- **Interactive Brass Loupe**: Draggable magnifying glass with 2.3x optical zoom and lens refraction to inspect fine project details.
- **Responsive Mobile Experience**: Fluid mobile-optimized touch interface and dedicated plate viewer.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS (CSS 3D Transforms, SVG Turbulence Filters)
- **Typography**: Instrument Serif & Newsreader via `next/font/google`
- **Icons**: [Lucide React](https://lucide.dev/)

##  Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
